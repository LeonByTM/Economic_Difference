1. PROJECT OVERVIEW
================================================================================

Purpose:
  Streamlit multi-page analytics dashboard analysing macroeconomic data
  (2011-2020) across 4 Asian economies: China, Hong Kong SAR China, India,
  Singapore.

Data source:
  AWS S3 — bucket: economic-warehouse-curated
  All data access goes through services/data_service.py (never directly in pages)

Entry point:
  Overview.py  (used as: streamlit run Overview.py)

Python version: 3.12
Key libraries: streamlit, plotly, pandas, boto3, python-dotenv

3. DATA RULES
================================================================================

Loaders (always import from services/data_service.py):
  load_development_master()  ->  GDP, Interest Rate, Unemployment, Population Growth
  load_macro_master()        ->  Brent Oil, US10Y Yield, VIX (daily)
  load_market_master()       ->  Stock Index Close, FX vs EUR (daily)

After loading, always do:
  df["country"] = df["country"].str.strip()

Country filter (always exclude Japan):
  countries = sorted(c for c in df["country"].unique() if c != "Japan")

Year range for all research pages (RQ1, RQ2, RQ3):
  year_range = (2011, 2020)
  Do NOT change this unless explicitly asked.

The 4 countries in scope:
  China, Hong Kong SAR China, India, Singapore

4. COLOR MAP — NEVER CHANGE
================================================================================

color_map = {
    "Singapore":           "#00aa55",   # Green
    "China":               "#1f77b4",   # Blue
    "Hong Kong SAR China": "#ff7f0e",   # Orange
    "India":               "#d62728",   # Red

This color map must be defined at the top of every page file and passed to
every Plotly figure via color_discrete_map=color_map.

5. PAGE STRUCTURE — EVERY RESEARCH PAGE MUST FOLLOW THIS ORDER
================================================================================

1. Imports
2. render_topbar(active="...")
3. st.title(...)
4. st.caption(...)  — persona + research question + period
5. Load data (load_development_master())
6. Strip country whitespace
7. Define color_map
8. Filters (st.multiselect for countries, year_range fixed to 2011-2020)
9. Filter dataframe to `view`
10. KPI cards (kpi_row([render_kpi_card(...)]))
11. insight_panel(...)  — summary bullets at top
12. st.divider()
13. Charts — each chart MUST be followed immediately by key_takeaways([...])
14. summary_table(...)
15. st.divider()
16. Conclusion box (st.markdown with styled div — see Section 7)

6. COMPONENT USAGE
================================================================================

--- key_takeaways ---
Import: from components.ui_helpers import key_takeaways
Call: key_takeaways(["bullet 1", "bullet 2", "bullet 3"])
Optional: key_takeaways([...], color="#1565c0")
Rule: MUST be called after EVERY st.plotly_chart(). No exceptions.
Bullets support <b>bold</b> HTML tags.

--- insight_panel ---
Import: from components.ui_helpers import insight_panel
Call: insight_panel("Panel Title", ["bullet 1", "bullet 2"], color="#1a237e", bg="#e8eaf6")
Rule: Used once per page near the top, after KPI cards.

--- render_kpi_card + kpi_row ---
Import: from components.ui_helpers import render_kpi_card, kpi_row
Usage:
  kpi_row([
      render_kpi_card("Label", "Value", "ICON", delta=0.5, color="#2e7d32", bg="#f7fbf4"),
      render_kpi_card("Label", "Value", "ICON"),
  ])
Rule: Used for all metric display blocks.

--- summary_table ---
Import: from components.ui_helpers import summary_table
Call: summary_table(view, agg_cols={"Display Name": "Column Name", ...})
Rule: Used once per page near the bottom, before conclusion.

--- add_events_to_fig ---
Import: from components.ui_helpers import add_events_to_fig
Call: add_events_to_fig(fig)
Rule: Always add to time-series line charts to mark economic events.

--- render_topbar ---
Import: from components.topbar import render_topbar
Call: render_topbar(active="Interest_Rate_Employment")
Active values: "Interest_Rate_Employment", "GDP_Divergence",
               "Population_Growth", "Market_Monitor"

9. CHART RULES
================================================================================

- All charts use Plotly Express or Plotly Graph Objects
- Render with: st.plotly_chart(fig, use_container_width=True)
- Always set: fig.update_layout(margin=dict(t=40, b=20))
- Always set: fig.update_yaxes(showgrid=False) on line charts
- For time-series: fig.update_xaxes(range=[year_min - 0.5, year_max + 0.5], dtick=2)
- Always set hovertemplate (never use default hover)
- For scatter with trendline: trendline="ols"
- ALWAYS call key_takeaways([...]) immediately after st.plotly_chart(...)

10. SECURITY RULES
================================================================================

NEVER:
  - Commit .env to git
  - Hardcode any credential, key, token, or password in any Python file
  - Push __pycache__/ or *.pyc files
  - Log or print credential values

ALWAYS:
  - Load secrets via python-dotenv and os.getenv() (done in config/settings.py)
  - Keep .env in .gitignore
  - Remind user to refresh AWS session token when app shows credential errors
    (token message: "AWS session expired. Update AWS_ACCESS_KEY_ID...")

For deployment secrets use:
  Streamlit Community Cloud -> App Settings -> Secrets (TOML format)
  NOT environment variables in the repo

12. COMMON ERRORS AND FIXES
================================================================================

ERROR: "AWS session expired..."
FIX:   Go to AWS access portal -> Get credentials -> copy Option 1 commands
       Update .env with new AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY,
       AWS_SESSION_TOKEN. Restart Streamlit.

ERROR: ModuleNotFoundError
FIX:   pip install -r requirements.txt

ERROR: Plotly chart missing color for a country
FIX:   Check that df["country"].str.strip() was called. Country name may have
       trailing whitespace that breaks the color_map lookup.

ERROR: key_takeaways not found
FIX:   Add to import: from components.ui_helpers import key_takeaways

ERROR: Git push rejected (non-fast-forward)
FIX:   git pull origin main --allow-unrelated-histories --no-edit
       Resolve any conflicts, then git push origin main
